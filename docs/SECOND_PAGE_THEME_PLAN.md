# 第二页主题与40个场景设计

状态：**四主题40关已实现**。2026-10-03。

首页第二页四个主题各开放十关，标注“十个轻松小场景”“开始游戏”。全部40个场景 ID 已接入旅程顺序、类型、组件路由、提示和本地语音映射。第一页四条旅程保持原样。

## 目录与共用规格

- 两页均为两列四宫格；目录下方有上一页、页码、下一页。第一页禁用上一页，第二页禁用下一页，不循环。
- 页码在 App 内保存；完成页“回到目录”保留页码；顶部品牌与刷新重置到第一页。翻页不发出音频反馈事件。
- 第二页卡片为可点击的十关旅程按钮。页码由 polite live region 播报；翻页后焦点转到可用的反向翻页按钮。
- 四张封面路径为 `public/images/themes/upcoming/{ocean,sky,life,music}-cover.webp`。封面不是40关的场景素材；每张源图片及构建图片均不得超过300,000字节。
- 实现使用 SceneProps、TapTarget、ForgivingDrag。每关只有一个主要动作；点击区域至少104×104 CSS像素；拖动默认在目标周边扩大72像素，支持 Enter/空格送到唯一目标。
- 表内提示为本地语音的准确文案，无障碍标签与实际操作对象一致。静止轻提示沿用现有机制；背景道具不表现为额外按钮。
- 非音乐关完成反馈约1.5–2.5秒，然后自动推进；音乐关使用下述6.4秒演奏时长。成功后禁用目标，onComplete只执行一次。计时兜底必须可清理，降低动态效果时也能推进。点错或拖偏只温和反馈，不出现失败、计时、成绩或催促。
- 每关素材需求含独立背景与透明交互层，按需增加完成态。默认素材目录 `public/images/themes/<主题ID>/`，以场景 ID 为文件名前缀，统一本地 WebP，每张不超过300,000字节。表内角色必须在操作前后保持造型一致。
- 每主题固定十关，成功后自动推进，最后进入独立完成页；可重玩整轮或返回第二页目录。40条提示、4条开场、4条夸奖与4条完成语音随网站发布；语音加载或播放失败不阻断流程。
- 音乐十关各使用匹配乐器音色创作的独立本地6.4秒演奏，播放结束后才推进；降低动态效果不缩短时长。演奏期间抑制背景旋律与提示语音。静音或音频失败仍等待6.4秒，停滞兜底7.9秒。创作与播放规则见 [乐器演奏说明](../public/audio/instruments/README.md)。

首关实现见 [首关实现说明](../src/themes/preview/README.md)，其余36关见 [扩展场景实现说明](../src/themes/expanded/README.md)。下表保留稳定 ID、构图、唯一目标、提示、无障碍标签、反馈及素材需求，供后续维护核对。
