# 放风筝素材

素材使用 Codex 内置 `image_gen` 生成，并以 `public/images/car.webp` 作为画风参考：暖棕柔和描边、圆润造型、明亮配色和绘本纸纹。

- `kite-flying-background.webp`：宽幅开阔草坡与蓝天，右上方留出风筝空间，左下方留给小车和线轴。
- `kite.webp`：透明背景的彩色菱形风筝，带三枚彩带尾饰，不含牵引线。
- `kite-spool.webp`：透明背景的大号红黄线轴，缠绕浅色细线，作为按住目标。

提示词摘要：儿童绘本风的晴朗开阔草坡；透明底、红黄蓝绿拼色的菱形风筝；透明底、圆润易握的红黄风筝线轴。无人物、文字、标识或水印。

建议语音：“按住大线轴，让风筝慢慢飞高。”
