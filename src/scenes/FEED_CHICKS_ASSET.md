# 喂小鸡素材

素材使用 Codex 内置 `image_gen` 生成，并以 `public/images/car.webp` 作为画风参考：暖棕柔和描边、圆润造型、明亮配色和绘本纸纹。

- `feed-chicks-background.webp`：宽幅晴天农场、草地、木栅栏和远处红色谷仓；不含小鸡或食碗。
- `feeding-chicks.webp`：透明背景的三只金黄色小鸡组合，作为可移动角色图。
- `grain-bowl.webp`：透明背景的大号木碗和金色谷粒，作为独立点击目标。

提示词摘要：儿童绘本风农场背景；透明底、朝右行走的三只友善小鸡；透明底、清晰易辨的大木碗与谷粒。无文字、标识或水印。

建议语音：“点一下大谷粒碗，请小鸡来吃。”
