# 回家车库场景素材

- 背景：`/images/home-garage-closed.webp` 与 `/images/home-garage-open.webp` 是同构图的本地黄昏住宅背景，分别用于车库门关闭和打开；小车继续复用 `/images/car.webp`。
- 使用：两张背景交叉淡入表现开门，车库门区域使用宽触控热区；小车驶入后由场景完成回调推进流程。
- 图片提示词：温暖绘本风的黄昏小住宅和宽阔车道，车库位于画面右侧，柔和金色天空与绿草地；构图清晰，为小汽车留出车道；生成车库门关闭与打开两种版本，打开版本露出温暖明亮的空车库，不出现车辆、文字或标识；画风与游戏内小汽车一致。
- 建议语音：“到家啦，点一点车库门，让小车回家吧。”
