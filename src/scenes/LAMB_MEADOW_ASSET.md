# 小绵羊吃青草素材说明

## 用途与构图

- `public/images/scenes/lamb-meadow.webp` 是小绵羊的独立角色图，供轻轻咀嚼青草并露出开心反馈的场景使用。
- PNG 使用透明 alpha 背景；小绵羊全身站立、四条腿完整可见，面向左侧草叶动画的位置，不包含草地或其它物件。
- 背景复用 `/images/feed-chicks-background.webp`；场景 CSS 负责青草移动和温柔的开心光点。
- 图片由内置 imagegen 生成，使用 `public/images/car.webp` 作为水彩绘本画风参考。
