# 小汽车修路

面向 3 岁左右儿童的轻量网页游戏。目标是一轮很短、操作直观、反馈温和，不设置失败压力。

## 当前版本

V1 已包含一轮可玩的旅程：从首页出发，依次清开石头、铺好木板过桥、点击红绿灯放行，最后到达完成页并重新开始。每关只有一个主要操作；场景会在动画结束后自动推进，不显示失败或计时压力。

家长设置可以分别开关背景音乐、互动音效和中文语音。音效由浏览器本地生成，语音使用设备已安装的中文语音；声音不可用时仍可继续游戏。声音选项保存在当前浏览器中。

产品目标和后续扩展方向见 [GAME_PLAN.md](./GAME_PLAN.md)。

## 本地运行

需要 Node.js 20.19 或更新版本，以及 pnpm。

```sh
pnpm install
pnpm dev
```

生产构建：

```sh
pnpm build
```
