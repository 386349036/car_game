# 小汽车修路

面向 3 岁左右儿童的轻量网页游戏。目标是一轮很短、操作直观、反馈温和，不设置失败压力。

## 当前版本

首页提供两条短旅程：原“小汽车修路”旅程包含 18 个场景；“小动物朋友”旅程包含 10 个场景，其中五关复用已有动物互动，另有五关为新场景。原旅程包括清开石头、过桥、红绿灯、换胎、雨刷、洗车、喂兔子、放风筝等内容，最后回家停车；动物旅程围绕小狗、小鸭、兔子、小鸡、小鱼、小猫、小鸟、小海龟、小绵羊和小象展开。每关只有一个主要操作；场景会自动推进，不显示失败或计时压力。

家长设置可以分别开关背景音乐、互动音效和中文语音。音效由浏览器本地生成，中文语音播放随游戏提供的音频文件，无需手机安装语音包；声音不可用时仍可继续游戏。声音选项保存在当前浏览器中。小车和场景插画为游戏内置的生成图片。

产品目标和后续扩展方向见 [GAME_PLAN.md](./GAME_PLAN.md)。

## 本地运行

需要 Node.js 20.19 或更新版本，以及 pnpm。

```sh
pnpm install
pnpm dev
```

生产构建：

```sh
pnpm build
```
