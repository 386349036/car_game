# 小汽车修路

面向 3 岁左右儿童的轻量网页游戏。目标是一轮很短、操作直观、反馈温和，不设置失败压力。

## 当前版本

目前完成 V1 的第一个开发子任务：网页项目外壳、首页、流程占位页、完成页，以及基础响应式布局。主按钮可在三个占位画面之间前进或重玩；正式关卡、声音和家长开关会在后续子任务中加入。

产品规格和后续任务边界见 [GAME_PLAN.md](./GAME_PLAN.md)。

## 本地运行

需要 Node.js 20.19 或更新版本，以及 pnpm。

```sh
pnpm install
pnpm dev
```

生产构建：

```sh
pnpm build
```
